# 🎮 TechPilot - Gaming Gear Landing Page

A modern and responsive gaming gear landing page built using **HTML5**, **CSS3**, and **JavaScript**. The website showcases premium gaming accessories with an engaging user interface, responsive layouts, and interactive frontend features.

---

## 📖 Overview

TechPilot is a frontend web application designed to showcase gaming products such as gaming mice, headsets, webcams, and other accessories. The project focuses on creating a visually appealing and user-friendly interface while demonstrating responsive web design and JavaScript interactivity.

---

## ✨ Features

- Responsive navigation bar
- Modern gaming-themed UI
- Hero section with Call-to-Action button
- About section with company information
- Featured gaming products
- Facts and services section
- Contact section
- Fully responsive design for desktop, tablet, and mobile devices
